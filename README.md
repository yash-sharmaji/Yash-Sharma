# 🚀 Yash Sharma — Full-Stack Portfolio

An interactive, high-performance portfolio crafted with the **MERN Stack** (MongoDB, Express, React, Node.js), **Tailwind CSS v4**, and **Framer Motion**, engineered around the **ShareX Neo-Brutalist design language** (`#183d2d` Forest Green, `#f5f0e8` Editorial Cream, `#1d1d1b` Ink Black, `#c0392b` Crimson Red).

---

## ✨ Features & Interactive Capabilities

1. **ShareX Design Language & Tokens**:
   - High-contrast 2px solid borders with hard offset neo-brutalist drop shadows (`shadow-[4px_4px_0px_#1a1a1a]`).
   - Clean typographic pairing: `Inter` for layout and `JetBrains Mono` for code, metrics, and badges.
   - Continuous marquee announcement ticker banner.

2. **Interactive Guided Tour (Driver.js & Framer Motion)**:
   - Click the prominent **"Take Tour"** button in the header or the first-visit welcome toast.
   - Custom `.cc-tour` popover styling matching ShareX with step indicators, backdrop spotlights, and confetti finale.

3. **Live Redis Mutex Lock Architecture Simulator**:
   - An interactive visualizer modal for **ShareX** demonstrating how atomic `SET NX PX` leases and Lua compare-and-delete scripts eliminate double-booking race conditions in shared campus inventory.

4. **Interactive Developer Console (`yash.config.ts`)**:
   - Tabbed environment switching between TypeScript configuration, Lua lock script, and engineering philosophy with a live simulation runner.

5. **Open Source Contribution Matrix**:
   - Dynamic searchable & filterable showcase of 18+ pull requests across 10+ repositories (Hacktoberfest, NSoC, CareerForge, Contribo, Open-Agents).

6. **Interactive Vibing Corner**:
   - Easter egg playground featuring Dancing Club Penguin & Pedro Pedro Pedro Raccoon with animated rhythm beat bars and developer quotes.

7. **Full MERN Contact Station**:
   - Express & MongoDB REST API (`/api/contact`) with automatic in-memory fallback, input validation, and real-time celebratory feedback.

## 🛠️ Quick Start

### 1. Run Full Stack (Client + Server concurrently)
```bash
cd Yash-Sharma
npm run dev
```
- **Client**: `http://localhost:5173`
- **Server**: `http://localhost:5000`

### 2. Production Build & Serve
```bash
npm run build
npm start
```
The server serves both the REST API and the production client build at `http://localhost:5000`.
